  <h1>moegramX Ghost</h1>
  <p>A personal Telegram X/TDLib client fork with local privacy and filtering features.</p>
</div>

## Features

- Ghost Mode with separate read controls for private chats, groups, and channels
- **Read until** a selected message
- Local shadow bans, including Telegram blocked-user integration
- Message and keyword filters

## Sources

- [moegramX](https://github.com/moeCrafters/moeGramX) — direct upstream; the app icon comes from its [`07dd6fb0`](https://github.com/moeCrafters/moeGramX/commit/07dd6fb0e65e240454f8807dfa633ce7caa4a382) icon update

- [AyuGram](https://github.com/AyuGram/AyuGram4A) — feature-behavior reference; this Telegram X/TDLib implementation is independent
